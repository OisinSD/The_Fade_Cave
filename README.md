# 💈 The Fade Cave

A modern, responsive, and lightweight website built for a local hair barbershop. Designed using vanilla HTML, CSS, and JavaScript, all packed into a single, file.

## Features
* **Responsive Design:** Looks great on mobile phones, tablets, and desktops.
* **Modern Aesthetic:** Clean layout tailored for a professional barbershop brand.
* **Single-File Architecture:** Fast-loading and easy to maintain without complex build steps.
